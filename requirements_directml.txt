# DirectML GPU 加速（仅 Windows，DirectX 12 设备；适用于 AMD / Intel 等非 NVIDIA 显卡）
#
# 注意：
#   * 不要与 onnxruntime 或 onnxruntime-gpu 同时安装，三者提供同一个 onnxruntime 模块。
#   * 安装后 backend/tools/hardware_accelerator.py 会自动探测到 DmlExecutionProvider，
#     并通过 PaddleOCR 的 engine='onnxruntime' 启用 GPU 推理。
#   * 首次使用某个模型时会自动下载官方 ONNX 模型（约 5~90MB/个）并缓存到
#     ~/.paddlex/official_models/，之后可离线使用。
#   * 若需完全离线部署，可改用 PaddleX 预转换：
#       pip install "paddlex[paddle2onnx]"
#       paddlex --paddle2onnx --paddle_model_dir <paddle模型目录> --onnx_model_dir <输出目录>
#     将生成的 inference.onnx 放到 backend/models/V5/<模型目录>/ 下即可被优先使用。
